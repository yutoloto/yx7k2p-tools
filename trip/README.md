# 旅のしおり

旅程・持ちもの・割り勘精算をまとめるPWA。麻雀スコア表と同じリポジトリで公開。

- 公開URL: https://yutoloto.github.io/yx7k2p-tools/trip/
- データは端末のlocalStorage（キー `trip_db_v1`）。サーバーには送らない
- 書き出し/読み込みでJSONバックアップ可

## 機能
- 旅を複数保存（何度でも使える入れ物）
- 行程: 日ごとのタブ／時刻・メモ・リンク／「厳守」マークで強調
- 持ちもの: タップでチェック、進捗バー、改行でまとめて追加
- お金: 人数無制限。項目ごとに「払った人」と「誰で割るか」を指定
  - 精算は最小回数に集約（誰が誰にいくら）
  - 請求文は金額と内訳だけを出力（負担区分の説明は入れない）
