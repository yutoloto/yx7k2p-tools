# 旅のしおり

旅程・持ちもの・立替の精算をまとめるPWA。麻雀スコア表と同じリポジトリで公開。

- 公開URL: https://yutoloto.github.io/yx7k2p-tools/trip/
- データは端末のlocalStorage（キー `trip_db_v1`）。サーバーには送らない
- 書き出し/読み込みでJSONバックアップ可
- 麻雀アプリ（`/`）とは **アイコン・manifest id・キャッシュ名（tabi-）がすべて別**。同じオリジンだがデータもキャッシュも混ざらない

## 画面
旅のフェーズで「いま」の中身が変わる。

| フェーズ | 「いま」に出るもの |
|---|---|
| 出発前 | 出発までの残り日数／持ちものの残りとその場チェック／出発時刻 |
| 旅行中 | つぎの予定＋カウントダウン／今日の「厳守」／立替合計・持ちもの残り |
| 終了後 | 精算（誰が誰にいくら）／総額／請求文への導線 |

- 行程: 日ごとタブ（日付つき）・縦レール・「いま」の線・過去は減光・「厳守」は朱で強調。タップで詳細（メモ内の電話番号は自動で発信リンク）
- 持ちもの: 大きなタップ行・「のこりだけ」表示・改行でまとめて追加・削除は編集モードでのみ出る
- お金: 金額を先に打つ立替入力。精算は最小回数に集約。**請求文は項目・金額・合計だけ**（負担区分の説明は入れない）
- メモ: 自動保存

## デザイン規律
Refero の「Ventriloc（Editorial data observatory）」から3点だけ借用。

1. **アクセント1色**: 朱 `#ff682c` は「いま」「厳守」「カウントダウン」など小さな印だけ。**主ボタンには使わない**（主ボタンは墨 `#202020` の塗り／角丸なし）
2. **タイポ**: 見出しは太らせず tracking `-0.02em`、本文16/1.5、キャプション14/1.43、数字は tabular-nums
3. **余白**: 4px基準（8/12/16/20/36）。影は使わず面の色差（`#fff` / `#efefef`）で階層を作る

ダークモードは `prefers-color-scheme` で反転する。
